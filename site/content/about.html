Route Map is built by OSINTPH.

What it does

Route Map places each router where its operator says it is. Backbone routers carry their site in their names, while an IP geolocation database often has only the country or the place where the address block was registered. So Route Map reads the operator's router names first, checks every placement against the speed of light in fibre, and says plainly where each placement came from, so the map shows the path the packets took.

FalconEye

The placement engine, routemap-engine, started in FalconEye, OSINTPH's web application, where it powers the Route Map tab. The desktop app runs the trace on your own machine instead of in a browser.
