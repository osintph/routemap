Route Map is built by OSINTPH.

Why

Most traceroute maps put each router where an IP geolocation database says it is. For backbone routers that is often where the operator registered the address block, not where the router stands, and the map ends up showing paths the packets never took. Route Map was written to do the opposite: believe the operator's own router names first, check every placement against the speed of light in fibre, and say plainly where each placement came from.

FalconEye

The placement engine, routemap-engine, started in FalconEye, OSINTPH's web application, where it powers the Route Map tab. The desktop app runs the trace on your own machine instead of in a browser.
