This website

getroutemap.app, not the app, counts visits with Cloudflare Web Analytics. Cloudflare, which serves the site, adds a small script from static.cloudflareinsights.com to each page, and the browser reports the visit back to this site's own address.

  • It records page views, the referring page, the visitor's country, browser, operating system and device type, and page load timings, as totals for the site.
  • It sets no cookies and uses no local storage. Cloudflare states that it does not "fingerprint" individuals by IP address, User Agent or any other data, so it does not follow a visitor across sites.
  • Cloudflare's own description: Cloudflare Web Analytics, and its privacy policy. Cloudflare publishes no privacy statement specific to Web Analytics beyond these.

The download links on this site go through /dl/, which sends your browser on to the same file on GitHub. For each download the server writes one line with the time, the release and file, the two-letter country Cloudflare passes on, the referring site cut to its address (a page on this site is written as site), and whether the browser looks like an automated client. It keeps no address and no browser string for these requests. The maintainer is told about downloads by email, with a daily summary; the lines are deleted after 30 days, and from then on only the number of downloads per day is kept. GitHub serves the file itself and sees the download as it sees any other; its privacy statement applies there.

For every other page, the web server keeps a standard access log (address, time, page, browser) for operating the site. The site itself sets no cookies; the light or dark choice is kept in your browser's local storage, and nothing is sent anywhere because of it. Every page reads fully with scripts turned off.
