This website

This part is about getroutemap.app, not the app. The site records visits and downloads for two reasons: download analytics (which platforms and versions people use, and where they find the project) and abuse prevention (telling people from scanners and bots).

Cloudflare

The site is served through Cloudflare and counts visits with Cloudflare Web Analytics, which sets no cookies. Cloudflare's privacy policy applies to what it handles.

Downloads

The download links on this site go through /dl/, which sends your browser on to the same file on GitHub. For each download the server writes one line to its download log with:

  • the time, and the release and file;
  • the two-letter country Cloudflare passes on with the request;
  • the network the request came from and its operator, as an AS number and name (for example "AS9299 Philippine Long Distance Telephone Co."), and whether that network looks like a home or mobile provider, an organisation, or a hosting provider; this is looked up on the server in IP Geolocation by DB-IP (DB-IP's IP to ASN Lite database, CC BY 4.0) and a list of hosting networks;
  • the kind of client: the browser and operating system family (such as "Firefox on Windows"), or the name of a tool (such as curl or a download manager), and whether a byte range was asked for;
  • the referring site cut to its address (a page on this site is written as site);
  • a daily visitor hash: a code made from your address and a random value that the server creates each day, keeps only in memory and throws away at midnight Manila time. The same address gives the same code for the rest of that day, so downloads within a day can be grouped (an installer and its checksums, for example). The code cannot be turned back into the address, and with the daily value gone, it cannot link downloads on different days.

The download log stores no address and no browser string, in any form, and neither do the server's error logs or the notifier that reads the log. The maintainer is told about downloads by email, with a daily summary. The lines are deleted after 30 days; from then on only the number of downloads per day is kept. GitHub serves the file itself and sees the download as it sees any other; its privacy statement applies there.

Google Analytics

The site also uses Google Analytics, but only if you accept it in the banner that appears on your first visit. Until you accept, and if you reject it, no Google script is loaded, no Google cookie is set and nothing is sent to Google.

  • If you accept, Google Analytics sets two cookies on this site: _ga, to tell visitors apart, and _ga_<ID>, to keep track of a visit; each lasts up to two years (browsers may cut that short).
  • Google then receives the pages you view, how you arrived, your browser, device and screen, scrolling and clicks on links that leave the site, and which download you click (file, platform and version), so the numbers can be compared with the download log. Google derives a coarse location (country, region, city) from your address; it states that Analytics does not log or store individual IP addresses of users in the EU, Switzerland or the UK.
  • Your choice is kept in your browser's local storage, not in a cookie. To change it, use Cookie settings at the foot of any page; withdrawing consent deletes the Google Analytics cookies and stops Analytics from loading.
  • Google's privacy policy and how Google uses information from sites that use its services apply to what Google receives.

Server logs and your browser

For every page other than the download links, the web server keeps a standard access log (address, time, page, browser) and an error log for operating the site; both are kept for 30 days. The light or dark choice and your Analytics choice are is kept in your browser's local storage; nothing is sent anywhere because of themit. Every page reads fully with scripts turned off, and then nothing from Google loads.
