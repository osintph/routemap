Open Visual Traceroute alternative: Route Map, native and open source

Route Map is a free, open source visual traceroute with native installers for Windows, macOS and Linux. It places each router by its operator's own hostname first, checks every placement against the round trip, and shows where each hop's location came from.

About Open Visual Traceroute

Open Visual Traceroute is a free, open source visual traceroute by Leo Lewis, written in Java and licensed under the LGPLv32,4. It runs on Windows, Linux, macOS and FreeBSD with a 3D globe or 2D map, whois and a Gantt view2,3. Its newest download is a Windows installer, 2.1.1, dated 10 June 2026; the newest macOS and Linux packages are 2.0.0, from January 20221.

What Route Map does not do

Route Map draws no submarine cables and labels no exchange points: the cable data is sold under licence, and PeeringDB's terms do not allow bundling its prefix list. Its Windows and macOS builds are not code-signed yet. It traces from your computer or from a server you already reach with ssh, and runs no measurement servers of its own. Its port test is a reachability check, not a port scanner.
