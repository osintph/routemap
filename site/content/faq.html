Questions

Why does Windows or macOS warn me?

The builds are not code-signed or notarised yet. Windows signing through SignPath Foundation is applied for; the steps to open the app anyway are on the download page, and every file can be checked against the GPG-signed checksums there.

Is it free? What is the catch?

It is free and open source under the GNU AGPL-3.0, with no ads, no tracking and no account. If it is useful to you, you can support it.

Where does a placement come from?

From the router's hostname first: CAIDA's Hoiho rules and carriers' own site codes. Only if the hostname says nothing does it fall back to an IP geolocation database (RIPEstat), and that answer must still pass the round-trip time check. The Source column and the marker colour say which.

Why is a hop drawn hollow, or dashed?

Hollow: the database knew only the country, so the marker sits in the country and the map does not zoom out for it. Dashed: the hop did not answer, or answered but could not be placed; the Unplaced panel says why.

What does it send, and to whom?

Only what the privacy page lists: public router hostnames to CAIDA Hoiho, public hop addresses to RIPEstat, reverse DNS to your own resolver, and, only if you have not set your location, your public IP to RIPEstat. Private and carrier NAT addresses are never looked up. Each source can be switched off.

Can I map a traceroute someone else ran?

Yes: File, Paste Trace, then say where it was run from. Output of traceroute, tracert and mtr works.

Does it need administrator rights?

No. It runs your system's own trace tool as you.

Is there a command line?

Yes, on every platform: command-line reference.

How do I report a bug?

Open an issue on GitHub, with your OS, the version (Help, About), what you traced and what you expected.
