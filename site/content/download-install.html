Windows

  1. Run the installer. Choose Install for me only (no administrator rights; it goes into your user folder) or Install for all users (always Program Files; Windows asks for administrator approval).
  2. Optional: tick Add routemap-cli.exe to PATH to use the command line in any terminal.
  3. Start Route Map from the Start menu. routemap.exe never opens a console; routemap-cli.exe beside it is the command line.

Upgrade: run the new installer; it replaces the old version and keeps your settings, history and databases. Uninstall: Settings > Apps > Installed apps > Route Map > Uninstall. Without installing: extract the zip and run routemap.exe in the Route Map folder; keep the folder together.

macOS

Open the .dmg for your Mac (Apple silicon or Intel: Apple menu > About This Mac says which) and drag Route Map to Applications. Upgrade: drag the new version over the old one. Uninstall: move Route Map from Applications to the Trash.

Linux

sudo apt install ./routemap-*-linux-x86_64.deb     # Debian, Ubuntu, Mint, Pop!_OS
sudo dnf install ./routemap-*-linux-x86_64.rpm     # Fedora, RHEL, Rocky, Alma
sudo zypper install ./routemap-*-linux-x86_64.rpm  # openSUSE

Route Map is then in the applications menu, and routemap is on the PATH (the same program is the window and the command line). Upgrade: install the new package the same way. Uninstall: sudo apt remove routemap or sudo dnf remove routemap. Without installing: chmod +x the AppImage and run it, or unpack the tar.gz and run ./routemap.

Your data: uninstalling keeps your settings, history and downloaded databases, so a later install picks them up. To remove them too, delete %APPDATA%\routemap (Windows), ~/Library/Application Support/routemap (macOS) or ~/.config/routemap (Linux). Check for Updates in the Help menu offers the right file for your system when a new version is out. From 0.2.0-beta.6 it can also download the file itself, check its signature and SHA-256, and then run the installer (Windows), open the disk image (macOS), open the package in your software installer (Linux .deb and .rpm) or replace the AppImage in place. These downloads go to GitHub directly and do not appear in this site's download statistics.

Not on PyPI: Route Map is not on PyPI. pip install routemap installs an unrelated project of the same name, not this app; Route Map comes only from its GitHub Releases and this page. Its engine is on PyPI as routemap-engine.
