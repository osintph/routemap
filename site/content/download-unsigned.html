The Windows build is not code-signed yet. Route Map has applied to SignPath Foundation, which signs open-source projects for free; until then Windows warns on first start.

  1. Extract the zip. Open the Route Map folder and run routemap.exe.
  2. If SmartScreen shows Windows protected your PC, choose More info, then Run anyway.
  3. If Microsoft Defender removes the file, check its SHA-256 against the signed list below, then see troubleshooting.
