macOS: the app is not notarised, so Gatekeeper blocks the first start. Right-click Route Map in Applications, choose Open, then Open again. On macOS 15: System Settings, Privacy & Security, Open Anyway. Or in Terminal: xattr -d com.apple.quarantine "/Applications/Route Map.app".

Linux: tracing needs traceroute (for example sudo apt install traceroute); mtr works too.

Windows: keep the Route Map folder together. routemap.exe is the app and never opens a console; routemap-cli.exe beside it is the command line.
