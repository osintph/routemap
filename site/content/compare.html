Route Map compared with VisualRoute and Open Visual Traceroute

Route Map is a free, open source visual traceroute for Windows, macOS and Linux. These pages set it beside two other visual traceroute tools, from each one's own pages, with the gaps on both sides marked.

  • Route Map and VisualRoute VisualRoute is a commercial tool for 64-bit Windows, sold as a perpetual licence in four editions.
  • Route Map and Open Visual Traceroute Open Visual Traceroute is a free Java tool under the LGPLv3; its newest macOS and Linux packages are from January 2022.
