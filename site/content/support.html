Report a bug

Please open an issue on GitHub Issues. If you would rather not use GitHub, email {{contact}}.

What helps most:

  • your OS and version, and the Route Map version (Help, About);
  • what you traced, what you expected and what you saw;
  • a screenshot, or a JSON export (File, Export). A JSON export contains the trace, so leave it out if the path is private;
  • for a hop in the wrong place: its hostname and address, and where it really is if you know.

Security issues: {{contact}}, encrypted to the release key if you like (security.txt).
